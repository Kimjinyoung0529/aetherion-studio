안녕하세요, AETHERION 팀이에요. 이번 업데이트는 두 가지 이유로 만들었어요. 하나는 [오늘 저녁 실제 접속 장애](/news/post/?p=2026-10-24-notice-outage-2)이고, 다른 하나는 [가상 시나리오 모의 보안 훈련](/news/post/?p=2026-10-24-blog-drill-ir)에서 찾은 빈틈이에요. (훈련은 가상 상황이었고, 실제 해킹은 없었어요.)

## 신규
- **① 외부 감시 강화**: 바깥 3곳에서 1분마다 점검해 2곳 이상 정상(200)일 때만 정상으로 봐요. 5xx·404·연결 끊김은 장애로 세고, 2번 연속이면 기본 연결을 자동으로 다시 시작해요.
- **② 감시가 눈을 감지 않게**: 점검 서비스가 응답하지 않으면 기록을 남기고, 5번 연속이면 안전하게 재연결해요.
- **③ 예비 터널 전용 감시**: 예비 경로 점검을 별도 프로그램으로 분리해, 멈추지 않고 404·오류 시 75초 안에 다시 연결해요.
- **④ 감시 하트비트**: 서버 상태(/health)에 자동 감시의 마지막 점검 결과와 경과 시간이 나와요.
- **⑤ 서버 멈춤 감지**: 프록시가 켜져 있지만 응답이 없으면(30초) 자동으로 다시 시작해요.

## 개선
- **⑥ 오류 응답도 전환**: 플레이그라운드가 연결 실패뿐 아니라 5xx·404 응답도 장애로 보고 다음 주소로 바로 넘어가요.
- **⑦ 서킷 브레이커**: 실패한 주소는 15초부터 최대 4분까지 점점 길게 건너뛰어요.
- **⑧ 오프라인 재시도 백오프**: 모든 주소가 안 되면 5·10·20…최대 60초 간격(약간의 무작위 지연 포함)으로 다시 확인해요.
- **⑨ 보안 제한**: 틀린 접속 키 1분 20회 초과 시 차단(429), 느린 연결 제한(헤더 15초·본문 120초, 408), 모든 API 응답에 보안 헤더(nosniff·프레임 차단·CSP 등).
- **⑩ 재부팅 대비·로그 관리**: 시작 스크립트가 모든 감시 프로그램을 함께 켜고, 로그가 2MB를 넘으면 자동으로 정리해요.

## 수정
- 감시가 3곳 중 1곳만 정상이어도 정상으로 보던 문제를 고쳤어요.
- 예비 경로 감시가 멈춰 장애를 놓치던 문제를 고쳤어요.

## 알려진 문제
- 예비 경로(runlocal)는 무료 중계라 몇 분 만에 주소가 바뀔 수 있어요. 바뀌면 자동으로 사이트 설정을 갱신하지만, 반영까지 1~3분 걸려요.
- 서버 컴퓨터가 완전히 재부팅되면 시작 스크립트를 한 번 실행해야 해요.
