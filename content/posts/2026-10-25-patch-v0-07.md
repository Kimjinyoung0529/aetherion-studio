안녕하세요, AETHERION 팀이에요.

## 신규
- **sandbox-runner**: 에이전트가 내린 셸 명령을 Docker 컨테이너 안에서 실행하는 Python 라이브러리·CLI [저장소](https://github.com/Kimjinyoung0529/sandbox-runner)를 열었어요(Apache-2.0). AETHERION 백엔드 샌드박스와 같은 기본 제한(메모리 768m, CPU 1.5, PID 256, 명령 타임아웃 60초)에 네트워크 차단, tmpfs 작업 폴더, 읽기 전용 루트, 유휴 세션 정리, 최대 세션 수 제한이 들어 있어요. 단위 테스트와 Docker 통합 테스트가 CI에서 돌아요.

## 개선
- 오픈소스 페이지의 sandbox-runner 카드를 "계획"에서 "뼈대"로 바꾸고 저장소 링크를 달았어요. 홈 푸터에도 링크를 추가했어요.

## 수정
- 없음

## 알려진 문제
- 컨테이너는 완벽한 보안 경계가 아니에요. 정말 믿을 수 없는 코드라면 gVisor나 microVM 같은 더 강한 격리를 함께 써야 해요. 보안 감사도 아직 받지 않았어요.
- 성능 수치는 아직 재지 않았어요.
