안녕하세요, AETHERION 팀이에요. v5는 "에이전트가 직접 해 보는" 버전이에요. 무엇이 되고 무엇이 아직 안 되는지 그대로 적을게요.

## 신규
- **가상 컴퓨터**: 에이전트가 서버의 격리된 리눅스 컨테이너에서 코드를 직접 쓰고 실행해요. `+` 메뉴의 "가상 컴퓨터에서 코드 실행"을 켜거나 `/컴퓨터`로 시작하면 돼요. 직접 명령을 치는 터미널 창도 있어요.
  - 컨테이너당 메모리 768MB, CPU 1.5개, 명령당 60초, 10분 쉬면 자동 정리. 쉬고 있을 때 실제 사용 메모리는 약 4MB였어요.
  - 일반 사용자 권한, 읽기 전용 루트, 네트워크는 기본 차단(켜도 외부 인터넷만, 서버 내부망 차단). 서버 파일에는 접근할 수 없어요.
- **이미지 생성 (SDXL-Turbo)**: `+` 메뉴 또는 `/이미지`로 그려요. 서버 CPU에서 stable-diffusion.cpp로 돌리고, 그리는 동안 언어 모델을 잠시 내려 메모리를 확보해요. 진행률(단계·디코딩)을 실시간으로 보여주고, 요청이 겹치면 줄을 세워요.
  - 실측(512px): 2단계 전체 약 27초(그리기 12.4초 + 변환 14.2초), 4단계 약 57초. 이 동안 채팅은 대기해요.
  - 요청받은 **Krea 2 Turbo는 넣지 못했어요.** 12B 모델에 가중치 파일이 26GB이고 GPU용이며 내려받으려면 별도 승인이 필요해서, CPU·메모리 15GB인 이 서버에서는 돌릴 수 없었어요. 대신 실제로 돌아가는 SDXL-Turbo(Stability AI Community License)를 쓰고, 화면에도 그렇게 표시해요.
- **대화 분기**: 어떤 질문이든 고쳐 보내거나, 어떤 답이든 다시 만들 수 있어요. 이전 버전은 `‹ 1/2 ›`로 오가며 볼 수 있어요.
- **포크**: 답변의 분기 버튼을 누르면 그 지점까지를 복사해 새 대화로 이어 가요.
- **모델 전환**: 설정 → 모델에서 Gemma 4 26B-A4B(기본), Kakao Kanana 1.5 15.7B-A3B, Kanana 2 3B 중 고를 수 있어요. 메모리를 지키려고 한 번에 하나만 올려요. 파일이 캐시된 상태에서 전환은 실측 3.5초(→Kanana 2 3B), 6.3초(→Gemma 4)였어요. 처음 불러올 땐 더 걸려요.
- **후속 질문 추천**: 답이 끝나면 이어서 물어볼 만한 질문 3개를 칩으로 보여줘요.
- **글쓰기 도구**: 답변의 글을 드래그하면 설명·요약·쉽게·다듬기·번역·인용해 묻기 버튼이 떠요.
- **대화 검색과 고정**: 사이드바에서 제목과 내용을 검색하고(Ctrl+K), 중요한 대화는 위에 고정해요.
- **단축키**: Ctrl+K 검색, Ctrl+Shift+O 새 대화, Ctrl+, 설정, Ctrl+/ 단축키 목록, Esc 중지.
- **창의성 조절**: 설정에서 temperature(0~1.5)를 바꿀 수 있어요.

## 개선
- **연결성**: 기본 주소를 Tailscale Funnel 고정 주소로 바꾸고, runlocal 터널을 예비로 두었어요. 기본 주소가 응답이 없으면 자동으로 예비 주소로 넘어가고, 전송이 시작되기 전에 실패하면 다음 주소로 한 번 더 보내요. 설정 → 연결에서 주소별 상태와 응답 시간을 보여줘요.
- 인터넷이 끊기면 위쪽에 안내가 뜨고, 다시 연결되면 자동으로 상태를 확인해요. 1분마다 서버 상태를 다시 확인해요.
- **생성 중 표시**: 답을 만드는 동안 입력창 테두리가 무지개빛으로 돌고 화면 가장자리가 은은하게 빛나요(동작 줄이기 설정에선 꺼져요).
- **메뉴 정리**: 첨부·템플릿·이미지 생성·가상 컴퓨터·도구 켜기는 `+` 메뉴 하나로, 고정·내보내기·단축키·설정은 `⋯` 메뉴로 모았어요. 설정은 연결·모델·개인화·읽어주기·데이터 탭으로 나눴어요.
- 아이폰: 메뉴가 화면 아래 시트처럼 열리고, 버튼 터치 영역을 키우고, 홈 인디케이터 영역을 피해요.
- 회사 홈페이지를 밝은 테마로 바꾸고 제품 영역·로드맵·연구 영역을 정리했어요. 직원 수나 고객 수 같은 숫자는 적지 않았어요(없는 숫자라서요).
- 서버: 모든 무거운 작업(채팅·추천·이미지·모델 전환)이 한 줄로 서서 메모리가 넘치지 않게 했어요. 감시 스크립트는 이미지 생성·모델 전환 중에는 언어 모델을 억지로 다시 켜지 않아요.

## 수정
- mermaid 다이어그램에서 화살표 라벨에 `<`, `>`가 있으면 그려지지 않던 문제.
- 도구 실행 과정에 검색어 대신 빈 칸이 보이던 문제(도구 인자 이름 불일치).
- 짧은 답변 뒤 속도 통계가 비어 보이던 문제.
- 다이어그램이 아주 작게 쪼그라들어 보이던 문제.
- 가상 컴퓨터·이미지 창이 넓은 화면에서 잘려 보이던 문제.
- 마지막 메시지에서만 수정·다시 생성이 되던 제한을 없앴어요.

## 알려진 문제
- 이미지를 그리는 30~60초 동안은 채팅이 대기해요(CPU 서버 한 대라서요).
- 가상 컴퓨터는 세션 동안만 유지되고, 10분 쉬면 파일이 지워져요.
- Kanana 모델은 이미지를 읽지 못해요(이미지 이해는 Gemma 4만).
