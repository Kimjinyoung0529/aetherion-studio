안녕하세요, AETHERION 팀이에요.

## 신규
- **도구 라우터 3차 학습 적용**: 2차에서 틀리던 유형을 겨냥해 이어서 학습했어요. 다시 측정한 결과 120문항 중 116개를 맞혔고, 도구가 필요 없는 질문 22개에서 잘못 도구를 부른 경우는 0건, 평균 약 0.34초였어요.
- **4차 학습은 적용하지 않았어요**: 남은 오답 5개를 겨냥해 예시 40개로 짧게 4차 학습을 해 봤지만 115/120으로 3차보다 나아지지 않아서 적용하지 않았어요.
- **키워드 보조 규칙**: 라우터가 아무 도구도 고르지 못했을 때만 동작하는 규칙 4가지를 넣었어요. 특정 문장이 아니라 일반적인 형태를 보고 판단해요.
  - 소수나 여러 번의 곱하기가 이어진 계산 → 계산기
  - 회사 이름 + 주가/시세 → 시세 조회 (한글 회사명도 종목코드를 자동으로 찾아요)
  - "○○이 뭐야", "○○이란" 같은 개념 질문 → 위키백과 (오늘·지금·최신 같은 실시간 표현이 있으면 제외)
  - QR + 아이디/계정/링크 → QR 코드
  - 결과: 내부 120문항 평가 116/120 → **120/120**, 잘못 도구를 부른 경우 0/22 유지예요.

## 개선
- **웹 검색 개선**
  - 검색 소스를 하나에서 둘로 늘려 동시에 찾아요(일반 웹 검색 + 뉴스).
  - 결과가 0건이면 검색어를 줄이거나 영문 표기만 남겨 자동으로 다시 찾아요.
  - 상위 페이지 3개를 동시에 읽고, 질문과 관련된 문장만 골라 답변에 넘겨요.
  - 출처에 답이 있으면 첫 문장에서 구체적인 숫자나 이름으로 답하고 출처 번호를 붙이도록 했어요.
  - "파라미터 수는?"처럼 짧은 후속 질문은 앞 질문의 대상을 붙여 다시 검색해요.
  - 이름과 사양을 함께 묻는 질문은 먼저 검색해요.
  - 빈 검색 결과는 캐시하지 않아요.
- 예: "크래프톤 Raon-1 mini 파라미터 수"를 물으면 이제 출처를 붙여 "총 28.8B, 그중 활성 4.3B"라고 답해요. 이어서 "파라미터 수는?"만 물어도 같은 답을 해요.

## 수정
- 검색 결과가 0건으로 나와 "정보가 없다"고 답하던 문제를 고쳤어요.
- 후속 질문에 검색 없이 일반적인 답만 하던 문제를 고쳤어요.

## 알려진 문제
- 120문항 평가는 규모가 작아서 실제 사용에서의 정확도는 다를 수 있어요. 키워드 규칙도 평가 문항 밖에서 계속 점검할게요.
- 검색 소스 응답이 느리면 답변까지 20~40초쯤 걸릴 수 있어요.
