안녕하세요, AETHERION 팀이에요. 이번엔 "얼마나 깊게 생각할지"를 직접 고를 수 있게 했어요.

## 신규
- 입력창 게이지 버튼 ⏲ 으로 **추론 모드**를 골라요. High · 깊게 생각 / Medium · 균형 / Low · 빠르게.
- 모드마다 실제로 다른 모델이 돌아가요. High는 Google Gemma 4 26B-A4B(UD-IQ3_S), Medium은 OpenAI gpt-oss-20b(MXFP4), Low는 Kakao Kanana 1.5 15.7B-A3B(IQ4_XS)예요.
- Medium용으로 gpt-oss-20b를 우리 서버에 새로 올렸어요. 직접 재 보니 초당 약 9 토큰, 메모리는 최대 약 10.7GB였어요.
- [모드별 사양](/models/) 페이지를 새로 만들었어요. 모델 이름, 양자화, 크기, 측정 속도, 라이선스를 모두 적었어요.

## 개선
- 채팅 화면에서는 모델 이름 대신 모드 이름만 보여요. 어떤 모델인지는 /models 페이지와 API 문서, 보안·프레스 페이지에 그대로 공개해요.
- 모드를 바꾸는 동안 "모드 전환 중…" 진행 상황이 보여요.
- High가 아닌 모드에서 이미지를 올리면 High로 바꾸자고 먼저 물어봐요.

## 수정
- 하위 페이지의 모바일 ☰ 메뉴에 API 문서, 플랜, 보안, 프레스 킷 링크가 빠져 있던 문제를 고쳤어요.

## 알려진 문제
- 서버 메모리가 15GB라 한 번에 한 모드만 켜져요. 모드를 바꾸면 10~40초 기다려야 해요.
- Medium과 Low는 이미지를 이해하지 못해요.
