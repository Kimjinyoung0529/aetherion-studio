02 / THE DESIGN
01 / REPRESENTATION

Pack ternary weights.

삼진 가중치를 2비트 슬롯에 저장하거나, 바이트당 5개를 묶어 평균 1.6비트/가중치로 압축합니다.

02 / EXECUTION

Compute with WGSL.

GPU 셰이더가 압축된 가중치를 직접 복원하면서 행렬·벡터 곱을 수행합니다. 가중치를 FP32 행렬로 다시 저장하지 않습니다.

03 / VALIDATION

Compare every output.

모든 출력값을 CPU 참고 연산과 비교합니다. WebGPU 실행이 없으면 성공했다고 표시하지 않습니다.

연구 단계 고지: 이것은 삼진 가중치 행렬 연산 코어와 정확도 벤치마크입니다. 현재 PrismML Bonsai 2 GGUF를 실행하는 LLM이 아닙니다. 실제 모델에는 PTQ1_0·PQ2_0 블록 포맷, 그룹별 스케일, Hadamard 전처리, Qwen3.5 하이브리드 어텐션, 토크나이저, KV 캐시 등이 필요합니다. 분할·압축 파일 크기만으로 iPhone 모델 실행을 보장할 수 없습니다.
