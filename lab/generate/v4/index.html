신경망 가중치 및 WGSL 컴파일 대기 중.

모델 가중치와 셰이더는 정적 파일로 다운로드되지만, 질문 처리와 추론 연산은 브라우저에서 수행됩니다. GPU 검증에 실패하면 생성 버튼을 활성화하지 않습니다.

01 / Q8 MODEL

Compact learned weights

직접 학습시킨 1층 Transformer의 임베딩과 투사 행렬을 Q8 가중치로 저장해 WebGPU에 전송합니다.

02 / CAUSAL ATTENTION

Predict the next character

레이어 정규화, Q/K/V, 인과적 어텐션, FFN, 출력 로짓을 GPU 셰이더에서 직접 계산합니다.

03 / GENERATION

One token at a time

다음 글자를 선택하고 새 입력에 추가하는 작업을 반복합니다. GPU 로그잇과 별도 CPU 기준 구현의 오차를 측정합니다.

연구 목적: 376자 어휘, 32차원 임베딩, 단일 인과적 어텐션 레이어, 96자 컨텍스트를 가진 초소형 실험 모델입니다. 한국어 질문 94쌍의 자체 예문과 376개 표현 변형으로 학습했으며, 자유 대화 성능은 제한적입니다. PrismML Bonsai 2B 가중치나 Qwen3.5 하이브리드 어텐션을 실행하는 엔진이 아닙니다. 이 실험은 LLM 추론의 구성 요소 중 하나인 실제 토큰 생성 경로를 검증하기 위한 것입니다.
