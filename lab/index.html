02 / COMPUTEWGSL shader

GPU에서 학습된 7,680개 가중치와 15개 편향을 사용해 행렬-벡터 곱을 수행합니다.

03 / OUTPUTDecision layer

GPU가 계산한 점수에 소프트맥스를 적용해 의도를 선택하고, 설명용 템플릿을 출력합니다.

현재 구현의 한계: WebGPU로 실행되는 실제 분류 신경망이지만, 범용 채팅·텍스트 생성·Noema 2B/4B 추론은 아직 제공하지 않습니다. 가중치는 실험용 한국어 예문으로 직접 학습했습니다. 다음 단계는 토큰화, 양자화 행렬 연산, 정규화, RoPE, 인과적 어텐션, KV 캐시, 자동 회귀 생성을 구현하는 것입니다. GPU 지연시간 측정값은 소형 분류 모델의 결과이며 대형 LLM의 속도를 의미하지 않습니다.
