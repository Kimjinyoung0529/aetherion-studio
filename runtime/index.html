03 / FIRST-PARTY GPU KERNEL RACE

Our own WGSL. Actually tested.

AETHERION이 직접 작성한 PTQ1_0/PQ2_0 압축 행렬 연산을 기존 1행 1스레드 방식과 32스레드 병렬 누산 방식으로 비교합니다. 같은 가중치·GPU·검증 코드를 사용합니다. 이 최적화 커널은 아직 일반 GGUF 전체 모델 실행기에 연결되지 않은 연구 기능입니다.

중요: AETHERION 자체 제작 부분은 GPU 프로필 선택기, 실행 스케줄러, 측정·비교 코드 및 별도 WGSL 실험 커널입니다. 범용 GGUF/MLC 모델의 전체 추론 연산은 각각 공개 Wllama/MLC 백엔드를 사용합니다. 모든 로컬 LLM을 하나의 자체 WebGPU 커널로 실행하는 제품은 아직 아니며, 기존 엔진보다 항상 빠르다는 보장도 없습니다. Safari·iPhone에서는 런타임/양자화/메모리 제한에 따라 실패할 수 있습니다.
