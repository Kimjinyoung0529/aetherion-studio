플랜

지금은 오픈 베타라서 모두 무료예요. 유료 플랜은 아직 없고, 생기면 소식에 미리 알려드릴게요.

오픈 베타 · 무료

  • 에이전트 채팅, 웹 검색, 딥 리서치
  • 모델 4종 전환 (Gemma 4 26B 기본)
  • FLUX 3 Image Klein 이미지 생성
  • 격리된 가상 컴퓨터에서 코드 실행
  • HTTP API (문서)

제한: GPU 없는 서버 한 대에서 돌아가서 동시 사용자가 많으면 느려질 수 있어요. 채팅은 IP당 분당 8회이고, 가동률 보장(SLA)은 없어요.
