플랫폼 · API

플레이그라운드가 쓰는 것과 같은 HTTP API예요. 여기에는 서버에 실제로 있는 엔드포인트만 적었어요. 오픈 베타라 SDK, SLA, 사용량 과금은 아직 없어요.

기본

  • 주소: 서버 상태 페이지에 표시되는 엔드포인트 (Tailscale Funnel HTTPS)
  • 인증: Authorization: Bearer <접속 키> 헤더 (/health는 제외). 키는 운영팀이 따로 전달해요.
  • 속도 제한: /api/chat은 IP당 분당 8회예요. 넘으면 429가 와요.
  • 요청 본문은 JSON, 채팅 응답은 Server-Sent Events(text/event-stream)예요.

엔드포인트

GET /health서버와 모델 상태, 현재 모델, 라이선스, 도구 목록 (인증 불필요)
POST /api/chat에이전트 채팅. {"messages":[...]}를 보내면 delta와 done(tokens, tok_s) 이벤트가 스트리밍돼요. 이미지는 High 모드(Gemma 4)에서만 돼요. 다른 모드면 400과 code: "need_high"를 돌려줘요.
POST /api/suggest대화를 바탕으로 다음 질문 제안
GET /api/models사용 가능한 모델 목록과 현재 모델
POST /api/models모델 전환 {"id":"gemma4"}(High · Gemma 4 26B-A4B), gptoss(Medium · gpt-oss-20b MXFP4), kanana15(Low · Kanana 1.5 15.7B-A3B), 그 밖에 gemma12, kanana3. 각 모델에는 tier, tier_label 필드가 있어요. 다시 불러오는 데 수십 초 걸려요.
POST /api/imageFLUX 3 Image Klein으로 이미지 생성 (prompt, size 384/512, steps 8/12/16). 512px 기준 약 2~3분 걸리고, 그동안 채팅은 잠시 멈춰요.
POST /api/computer격리된 가상 컴퓨터(Docker): exec, write, read, list, reset, status
POST /api/feedback답변 평가 {"rating":"up"|"down"}

예시

curl -N "$AE_URL/api/chat" \
  -H "Authorization: Bearer $AE_KEY" \
  -d '{"messages":[{"role":"user","content":"안녕!"}]}'
